Define how AI systems should interact with vault content.

This document establishes retrieval priorities, evidence expectations, and synthesis boundaries.

---
# Retrieval Rules

AI systems should:
- prioritize canonical documents
- preserve source attribution
- distinguish validated vs draft content
- avoid unsupported synthesis

---
# Source Hierarchy

1. Canonical operational documents
2. Validated frameworks
3. Approved playbooks
4. Executive summaries
5. Draft content
6. Archived material

---
# AI Usage Constraints

AI-generated outputs should:
- separate facts from interpretations
- preserve uncertainty where appropriate
- avoid fabricated citations
- reference canonical concepts when possible
- avoid overstating confidence

---
# Operational Principles

AI should function as:
- synthesis layer
- retrieval accelerator
- critique engine
- drafting assistant

AI should not function as:
- authoritative source of truth
- unsupervised governance layer
- unvalidated decision-maker

---
# Long-Term Objective

Enable reliable:
- local RAG systems
- AI copilots
- semantic retrieval
- automated briefing generation
- publishing automation
