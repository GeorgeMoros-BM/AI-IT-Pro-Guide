# Design Principles

## Canonical Concepts
Core concepts should have authoritative reference notes.

Examples:
- AI-Governance
- PromptOps
- Enterprise-RAG
- Agentic-Workflows
- Evaluation-Frameworks

These become semantic anchors.

## Focused Note Granularity

Preferred:
- coherent topic boundaries
- operationally meaningful chunks
- reusable concepts

Avoid:
- giant monolithic documents
- fragmented atomic notes without standalone value

## Semantic Linking

Links should:
- connect related concepts
- reinforce canonical references
- improve navigation
- support retrieval relationships

Avoid decorative or excessive linking.

# Future AI Compatibility

This architecture intentionally supports:
- local RAG systems
- semantic search
- AI copilots
- knowledge graphs
- AI-assisted briefing generation

# Retrieval Hierarchy

Preferred retrieval order:

1. Canonical operational documents
2. Validated frameworks
3. Approved playbooks
4. Executive summaries
5. Draft content
6. Archived content

# Operational Goal

The vault should function as a structured semantic system rather than a flat markdown archive.
