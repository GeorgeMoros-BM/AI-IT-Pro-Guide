Provide a structured mechanism for evaluating enterprise AI platforms and vendors.

---
# Evaluation Categories

| Category | Focus |
|---|---|
| Security | Data handling and compliance |
| Governance | Administrative controls |
| Capability | Functional breadth and depth |
| Integration | APIs and ecosystem fit |
| Economics | Licensing and operational cost |
| Reliability | Stability and support |
| Vendor Viability | Long-term sustainability |

---
# Security Evaluation

Questions:
- Is customer data retained?
- What certifications exist?
- Is tenant isolation supported?
- What logging exists?

---
# Governance Evaluation

Assess:
- role-based access control
- audit logs
- policy enforcement
- prompt governance
- data controls

---
# Capability Evaluation

Evaluate:
- model quality
- context handling
- tool use
- workflow support
- retrieval compatibility

---
# Economic Evaluation

Assess:
- licensing model
- token costs
- scaling economics
- support costs
- implementation burden

---
# Strategic Risks

- vendor lock-in
- proprietary workflow dependency
- pricing instability
- ecosystem fragmentation

---
# Recommended Outputs

- vendor scorecard
- architecture assessment
- TCO estimate
- governance assessment
- executive recommendation

---
# Strategic Guidance

Do not evaluate AI platforms solely on model quality.

Evaluate:
- operational fit
- governance maturity
- integration quality
- long-term maintainability
