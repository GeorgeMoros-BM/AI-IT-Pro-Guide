## Security & Governance Watch
_Impacts: InfoSec, Legal, Risk Management_

- **[OpenClaw Adds Auditable Security Primitives for Agents](https://openclaw.ai/blog/where-openclaw-security-is-heading)**
    - **The risk:** Autonomous agents with filesystem, command, and network access create material data-exfiltration, policy-bypass, and auditability risks.
    - **Our posture:** Require root-bounded filesystem controls, policy-driven egress, command approvals, and trust evidence from any agent framework before production access.
- **[Sandboxing Becomes a Baseline Requirement for Autonomous Agents](https://x.com/daytonaio/status/2055508571794927957)**
    - **The risk:** Production agents without sandbox isolation can overreach into filesystems, networks, and cloud environments.
    - **Our posture:** Add sandbox evidence to AI vendor RFPs and block production agent deployments that cannot demonstrate isolation, logging, and least-privilege execution.
- **[AI-Era Attack-Surface Reduction Moves Into CISO Scope](https://www.infosecurity-magazine.com/news-features/what-mythos-gptcybe-ai-mean-for/)**
    - **The risk:** AI-enabled development and agent tooling can expand dependency, model-abuse, prompt-injection, and supply-chain exposure.
    - **Our posture:** Build an AI asset inventory, segment agent runtimes, review high-risk dependencies, and require security ownership for each deployed AI workflow.
- **[Learnrights Proposal Raises Future Training-Data Licensing Risk](https://mitsloan.mit.edu/ideas-made-to-matter/how-learnrights-would-compensate-creators-ai-model-training)**
    - **The risk:** A proposed creator-compensation model for AI training data could create future licensing, attribution, or procurement obligations.
    - **Our posture:** Ask legal and vendor-management teams to review training-data provenance clauses, fine-tuning datasets, and third-party model indemnity language.
- **[Medium-Confidence GitHub Actions `pull_request_target` Callout Highlights Supply-Chain Risk](https://x.com/HotAisle/status/2054349973307974016)**
    - **The risk:** Misused privileged GitHub Actions workflow triggers can expose repositories and automation workflows to supply-chain compromise.
    - **Our posture:** Audit all AI and developer-tool repositories for privileged workflow triggers, especially `pull_request_target`, write-token exposure, and untrusted dependency-install steps.
