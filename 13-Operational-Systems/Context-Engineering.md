## Definition

Context engineering is the discipline of designing the information environment presented to AI systems.

This includes:
- prompts
- retrieval
- memory
- metadata
- system instructions
- workflow state
- external tools

---
# Core Principle

Model quality matters less than context quality more often than most organizations realize.

---
# Core Components

| Component | Purpose |
|---|---|
| System Instructions | Behavioral control |
| Retrieval Context | Knowledge grounding |
| Memory | Workflow continuity |
| Metadata | Semantic clarity |
| Tool State | Operational awareness |
| User Intent | Task alignment |

---
# Enterprise Context Sources

Typical sources:
- SharePoint
- ERP systems
- CRM platforms
- ticketing systems
- operational databases
- document repositories

---
# Common Failure Modes

- oversized context windows
- irrelevant retrieval
- weak metadata
- poor source hierarchy
- stale information

---
# Strategic Insight

The future competitive advantage in enterprise AI is likely to come more from:
- context architecture
- retrieval quality
- operational integration

than from raw model access alone.
